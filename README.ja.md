> ツール自体の画面は 5 言語に対応しており、ツールの **設定 → 言語** で切り替えられます。

## 免責事項

- **無料・オープンソース**：Python、画像認識、OCR、UI 自動化を学ぶための個人プロジェクトで、費用は一切かかりません。
- **画面を見てマウスを動かすだけ**：ゲームのメモリやファイルを読んだり変更したりはしません。
- **自己責任**：自動化ツールはゲームやプラットフォームの利用規約に違反する可能性があります。アカウント制限・停止・報酬回収のリスクは利用者が負います。
- **非公式**：ブラウンダスト2 の開発会社・運営会社・プラットフォームとは一切関係ありません。
- **営利利用の禁止**：代行、スクリプト販売、有料代行など営利目的での利用は認めていません。

## 機能

- **デイリー一括実行**：ギルド、マイハウス、酒場、常連客の聖石、高速狩猟、無料ガチャ、不要装備、製錬、女神像、鏡戦争、イベント戦闘、クエスト報酬、パス、メール、イベント報酬をボタン一つで順番に。
- **毎週の周回**：ストーリーカセットの吸収・招集・制圧を自動で使い、一週間分を毎日に分けて実行。
- **毎日の交易周回**：購入、調理、販売カレンダーに沿った販売。残す数は自分で決められます。
- **ウィークリー一括実行**：アーケードメニュー、マイハウス人気、装備製作、終末の書。
- **分身デスクトップ**：ゲームは見えない別のデスクトップで動くので、マウスとキーボードはそのまま使えます。
- **魔獣追跡者**：F8 で自分の戦い方を一度録画すれば、以降は毎ターンの順番・配置・スキルを録画どおりに並べてから戦います。
- **今日のレポート**：今日何を実行したか、どれが失敗したか、その理由がひと目でわかります。

## 特長

- **確信がなければ押さない**：画面をはっきり認識できたときだけクリック。詰まったらホームに戻るか停止します。
- **課金しない**：有料スタミナ、ダイヤ、有料アイテムには一切触れません。無料回数を使い切ったら止まります。
- **見張らなくていい**：終わったら Windows の通知でお知らせします。
- **自動アップデート**：起動のたびに新しいバージョンを確認するので、再ダウンロードは不要です。
- **1080p・2K・4K**：16:9 ならどれでも使えます。

## 3 ステップで開始

1. [Releases](https://github.com/nobell001/YES-BD2/releases/latest) から **`yes-bd2-win32-online-setup.exe`**（約 5 MB）をダウンロードしてインストール。インストール中に残りをダウンロードするので、ネットに接続したままにしてください。「Windows によって PC が保護されました」と出たら **詳細情報 → 実行** を押してください（インストーラーにコード署名がないため、新しいリリースではこの警告が出ます）。
2. ゲームの言語を**簡体字中国語**に、画質を FHD にする。
3. ツールを開いて **デイリー一括実行** を押す。ゲームが開いていなければ、起動するか確認されます。

> 実行中も PC を使いたいときは **分身デスクトップで実行** を押してください（Windows Pro が必要。初回のみ設定があります）。

## 実行前の注意

- 画面ロック、画面オフ、スリープにしないでください。ゲームウィンドウも最小化しないでください。
- GPU フィルター、シャープ、FPS 表示、録画オーバーレイなど、画面に重なるものはオフに。
- 通常モードはマウスを使うので、実行中は PC を操作しないでください。並行して使うなら分身デスクトップを。
- 起動のたびに管理者権限を求められます（Windows が一度確認します）。「はい」を押してください。

## 困ったときは

| 状況 | 対処 |
|---|---|
| ゲームが見つからない | 先にゲームを開いてください。標準以外の場所に入れている場合は、下の「ソースから実行」のパス設定を参照 |
| 画面を認識できない | ゲーム言語が簡体字中国語か、16:9 か、ゲームを隠しているものがないか確認 |
| ある項目が毎回失敗する | 今日のレポートで失敗理由とスクリーンショットを確認し、[Issues](https://github.com/nobell001/YES-BD2/issues) で教えてください |

今日のレポートのスクリーンショットがあると一番助かります。ゲーム内のアカウント情報が写ることがあるので、投稿前に確認してください。

## どのファイルをダウンロードするか

| ファイル | 説明 |
|---|---|
| `yes-bd2-win32-online-setup.exe` | **これを選んでください**。約 5 MB。残りはインストール中にダウンロード、たいていこちらが速い |
| `yes-bd2-win32-Full-setup.exe` | オフライン用の完全版。ファイルが大きいので、インストール中にネットにつなげない場合だけ |

GitHub が自動で付ける `Source code` の圧縮ファイルと `yes-bd2-win32.zip` はインストーラーではないので、プレイヤーには不要です。

<details>
<summary><b>ソースから実行（開発者向け）</b></summary>

ソースからの実行は**自動で更新されません**。`git pull` してください。

```powershell
git clone https://github.com/nobell001/YES-BD2.git
cd YES-BD2
py -3.12 -m venv .venv
.\.venv\Scripts\pip install -r requirements.txt
.\start.bat
```

ゲームが標準の場所にない場合は、起動前に次を設定します。

```powershell
$env:OK_BD2_LAUNCHER_PATH = "C:\Path\To\Browndust2Starter.exe"
$env:OK_BD2_GAME_PATH = "D:\Path\To\BrownDust II.exe"
```

依存関係は `pyproject.toml` と `uv.lock` が基準です。`requirements*.txt` は uv で出力したものなので手で編集しないでください。

```powershell
.\scripts\run_checks.ps1 -Mode Focused -Tests tests.test_pvp_task   # 影響のあるテストだけ
.\scripts\run_checks.ps1 -Mode Final                                # コミット前の完全チェック
```
