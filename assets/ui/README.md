# UI pictures

Pictures used only by the new main window (`src/ui/shell`).

- `icons/`: Lucide icons (ISC licence, see `icons/LICENSE`), stroke SVGs
  tinted at runtime.
- `cartridges/`: cartridge shells cut out of the recognition templates in
  `recognition-assets/template-assets/shop/cartridges` (S = story, R =
  character), background made transparent.
- `dishes/`: copies of the cooking templates in
  `recognition-assets/template-assets/image/Shop`; `index.json` maps the
  dish name to its file.
  The 地狱火紫菜包饭 template was captured greyed out, so its copy here is
  brightened (×2.2 per channel) to match the other dishes.
- `items/`: sale-item icons, see `items/SOURCE.md`.
- `bargain/sticker.png`: the 循环砍价 picture, a 贴纸 (sticker) cut out of
  Leo's 4K game screenshot (2026-10-11), dark background made transparent.
  Game art belongs to the game's publisher.
- `cartridges/SQUARE.png`: the 梦幻广场 card's label art, a copy of the
  recognition template `Q_square.png` (the 跑商 page's 买 card).
