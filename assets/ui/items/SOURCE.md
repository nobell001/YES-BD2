# Item icons

The sale-item icons in this folder (64×64 PNG, resized) come from BD2DB
(https://browndust2-db.souseha.com/), which hosts the game's own item art
(`https://image-bd2db.souseha.com/new_items/<itemId>.webp`).

The artwork belongs to the game's publisher (Brown Dust 2, NEOWIZ). It is
used only to show which item the trade task sells. `index.json` maps each
item's Simplified Chinese name (as the game client shows it) to its file.

Not from BD2DB (added 2026-11-10 for the game's 11-19 update):

- `slime_*.png`, `contract_*.png`: 史莱姆 and 招募契约书, cut out of Leo's own
  bag screenshots (简中 client), background made transparent.

The seven 额外料理 sold in the calendar (藏红花甜茶 `icon_food2016_16`,
土豆汤 `icon_food2006_6`, 黑啤酒炖锅 `icon_food2008_8`, 凯洛养身汤
`icon_food2027_27`, 巧克力面包 `icon_food2028_28`, 水果冰沙 `icon_food2030_30`,
三文鱼芥末寿司 `icon_food2020_20`) are BD2DB item icons like the rest
(2026-11-23; before, they used the tan recipe-card art from `../dishes/`,
which stood out in the 出售日历).
